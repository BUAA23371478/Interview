## 一、技术栈与工具链

| 类别 | 选型 | 版本 | 说明 |
|------|------|------|------|
| 框架 | React | 18.x | 函数组件 + Hooks，不引入类组件 |

| 国际化 | 无 | - | 项目仅中文用户，无需 i18n |

## 二、路由设计

```
/                          →  首页（模式选择）
/practice                  →  刷题模式主页（输入主题）
/practice/:sessionId       →  刷题进行中（出题 ↔ 答题 ↔ 反馈 循环）
/interview                 →  模拟面试设置页（输入 JD / 简历 / 轮数）
/interview/:sessionId      →  模拟面试进行中（一问一答流程）
/interview/:sessionId/report →  模拟面试复盘报告（只读）
/history                   →  历史记录总览
/history/practice          →  刷题历史列表
/history/interview         →  面试历史列表
/history/interview/:id     →  某次面试的详情与复盘的详情页
```

**路由守卫**：无登录态时，统一弹用户名输入框（单用户本地体验，不涉及真正鉴权）。

### 4.2 刷题模式 — 主题输入页（PracticeSetup）

**功能**：用户输入主题，系统校验后开始刷题。

**状态流转**：
```
初始状态 → 用户输入 → 点击「开始刷题」
  → POST /api/practice/validate-topic
    → 校验通过，返回 sessionId → 跳转 /practice/:sessionId
    → 校验失败 → 显示错误提示（"请输入技术面试相关主题"）
    → 超长提示 → "主题请控制在50字以内"
```

**组件实现**：
```typescript
// PracticeSetup.tsx
const PracticeSetup: React.FC = () => {
  const [topic, setTopic] = useState('');
  const [error, setError] = useState('');
  const [loading, setLoading] = useState(false);
  const navigate = useNavigate();

  const handleStart = async () => {
    if (topic.length > 50) {
      setError('主题请控制在50字以内');
      return;
    }
    setLoading(true);
    try {
      const res = await api.post('/api/practice/validate-topic', { topic });
      navigate(`/practice/${res.sessionId}`);
    } catch (e: any) {
      setError(e.message || '请输入技术面试相关主题');
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="max-w-2xl mx-auto p-8">
      <h1>选择刷题主题</h1>
      <Input
        value={topic}
        onChange={e => setTopic(e.target.value)}
        placeholder="例如：Java 后端开发、MySQL 优化、Redis 缓存"
        maxLength={50}
      />
      {error && <p className="text-red-500">{error}</p>}
      <Button onClick={handleStart} loading={loading}>开始刷题</Button>
    </div>
  );
};
```

### 4.3 刷题模式 — 答题循环（PracticeSession）

**核心交互**：这是整个前端最复杂的状态机。

**状态机设计**：

```
                    ┌──────────────────────┐
                    │     LOADING_QUESTION  │ ← 进入页面 / 点击"下一题"
                    └──────┬───────────────┘
                           │ SSE: question 到达
                    ┌──────▼───────────────┐
                    │     ANSWERING          │ ← 用户正在输入答案
                    └──────┬───────────────┘
                           │ 点击「提交」
                    ┌──────▼───────────────┐
                    │     SUBMITTING         │ ← 等待评分+解析
                    └──────┬───────────────┘
                           │ SSE: feedback 到达
                    ┌──────▼───────────────┐
                    │     FEEDBACK_SHOWN     │ ← 展示评分+解析
                    └──────┬───────────────┘
                           │ 点击「下一题」
                           │ 循环回 LOADING_QUESTION
                           └──────────────────┘
```

**组件结构**：

```typescript
type PracticePhase =
  | 'loading_question'
  | 'answering'
  | 'submitting'
  | 'feedback_shown';

interface PracticeState {
  phase: PracticePhase;
  sessionId: string;
  topic: string;
  currentQuestion: Question | null;
  userAnswer: string;
  feedback: Feedback | null;
  questionIndex: number;
  difficulty: number;          // 1-5 档
  consecutiveCorrect: number;  // 连续答对数
  consecutiveWrong: number;    // 连续答错数
  isStreaming: boolean;        // 是否正在接收 SSE 流
  streamingContent: string;    // 流式拼接中的内容
}

  id: string;
  content: string;             // Markdown
  type: 'short_answer' | 'choice';
  options?: string[];          // 选择题时才有的选项
}

interface Feedback {
  score: number;               // 0-100
  isCorrect: boolean;
  correctAnswer: string;       // Markdown
  analysis: string;            // 解题思路
  knowledgePoints: string[];   // 考察知识点
  commonMistakes: string[];    // 常见错误
}
```

**SSE 连接管理**：

```typescript
// hooks/usePracticeSSE.ts
const usePracticeSSE = (sessionId: string) => {
  const [state, dispatch] = useReducer(practiceReducer, initialState);

  const connectSSE = useCallback((endpoint: string) => {
    const eventSource = new EventSource(
      `/api/practice/${sessionId}/${endpoint}`
    );

    eventSource.onmessage = (event) => {
      const data = JSON.parse(event.data);

      switch (data.type) {
        case 'question_chunk':
          // 流式拼接题目内容
          dispatch({ type: 'APPEND_QUESTION_CHUNK', payload: data.content });
          break;
        case 'question_done':
          // 题目完整到达
          dispatch({ type: 'SET_QUESTION', payload: data.question });
          break;
        case 'feedback_chunk':
          dispatch({ type: 'APPEND_FEEDBACK_CHUNK', payload: data.content });
          break;
        case 'feedback_done':
          dispatch({ type: 'SET_FEEDBACK', payload: data.feedback });
          eventSource.close();
          break;
        case 'error':
          dispatch({ type: 'SET_ERROR', payload: data.message });
          eventSource.close();
          break;
      }
    };

    eventSource.onerror = () => {
      dispatch({ type: 'SET_ERROR', payload: '连接中断，请重试' });
      eventSource.close();
    };

    return eventSource;
  }, [sessionId]);

  return { state, dispatch, connectSSE };
};
```

**追问机制**：后端通过 SSE 事件类型 `follow_up` 控制。前端收到 `follow_up` → 状态回到「用户作答中」，但不递增轮次。

**进度条**：
```
████████████░░░░░░░░  第 3/10 轮
```

**核心组件**：

```typescript
const InterviewSession: React.FC = () => {
  const { sessionId } = useParams();
  const [messages, setMessages] = useState<InterviewMessage[]>([]);
  const [phase, setPhase] = useState<InterviewPhase>('waiting_question');
  const [currentRound, setCurrentRound] = useState(1);
  const [totalRounds, setTotalRounds] = useState(10);
  const [userAnswer, setUserAnswer] = useState('');
  const navigate = useNavigate();

  // SSE 连接
  useEffect(() => {
    const es = new EventSource(`/api/interview/${sessionId}/stream`);

    es.addEventListener('question_start', () => {
      setPhase('receiving_question');
    });

    es.addEventListener('question_chunk', (e) => {
      appendToLastMessage(JSON.parse(e.data).content);
    });

    es.addEventListener('question_done', () => {
      setPhase('answering');
    });

    es.addEventListener('follow_up', (e) => {
      // 追问：不递增轮次，开始新一轮流式接收追问
      setPhase('receiving_question');
      appendMessage({ role: 'interviewer', content: '' });
    });

    es.addEventListener('feedback_chunk', (e) => {
      // 面试官简短回应，流式拼接
      appendToLastMessage(JSON.parse(e.data).content);
    });

    es.addEventListener('round_advanced', (e) => {
      setCurrentRound(JSON.parse(e.data).round);
    });

    es.addEventListener('interview_complete', (e) => {
      es.close();
      navigate(`/interview/${sessionId}/report`);
    });

    return () => es.close();
  }, [sessionId]);

  const submitAnswer = async () => {
    setPhase('submitting');
    addMessage({ role: 'user', content: userAnswer });
    setUserAnswer('');
    await api.post(`/api/interview/${sessionId}/answer`, {
      answer: userAnswer,
    });
    // 之后由 SSE 事件驱动状态流转
  };

  // ... render
};
```

## 五、API 接口清单（前端视角）

### 5.1 刷题模式

| 方法 | 路径 | 请求体 | 响应 |
|------|------|--------|------|
| GET | `/api/user` | - | `{ userId, username }` |
| POST | `/api/user/register` | `{ username }` | `{ userId, username }` |
| POST | `/api/practice/start` | `{ topic }` | `{ sessionId }` |

## 八、错误处理与边界状态

| 场景 | 前端处理 |
|------|---------|
| SSE 连接中断 | 显示「连接中断，点击重试」按钮，重连时带上当前状态 |

| 流式输出中断 | 保留已接收内容，展示「生成中断」标记 + 重试按钮 |
| 页面刷新 | 从 URL 恢复 sessionId，调 `/status` 恢复状态 |

### 10.2 SSE 重连策略

```typescript
const createSSEConnection = (
  url: string,
  handlers: SSEHandlers,
  maxRetries = 3
) => {
  let retries = 0;
  let es: EventSource;

  const connect = () => {
    es = new EventSource(url);

    // 注册事件处理器
    Object.entries(handlers).forEach(([event, handler]) => {
      es.addEventListener(event, handler);
    });

    es.onerror = () => {
      es.close();
      if (retries < maxRetries) {
        retries++;
        setTimeout(connect, 1000 * retries); // 指数退避
      } else {
        handlers.onFatal?.();
      }
    };
  };

  connect();
  return () => es.close();
};
```

## P2. 这是什么项目？

**3 个 bullet**：
- 🎯 **做什么**：模拟真实面试官，对你进行多轮提问、追问、点评
- 💡 **为什么**：面试练习成本高、反馈不及时、缺乏针对性
- 🚀 **怎么用**：上传 JD + 简历 → AI 出题 → 答题 → 立即评分 + 复习建议

**底部**：产品截图（首页 + 答题界面）

---

## P3. 解决了什么问题？

| 用户痛点 | 本项目方案 |
|---|---|
| 找朋友模拟面试太麻烦 | 7×24 在线，AI 随时可练 |
| 不知道该练什么 | 根据 JD 自动生成题目 |
| 答完不知道哪里错 | 立即评分 + 指出遗漏点 + 追问深挖 |
| 错过的题下次还会错 | 错题自动入库 + 复习计划 |

## P5. 技术架构（一句话版）

**简化版架构图**（少细节，多概念）：

```
    用户 ←─→ 网页 ←─→ 后台 ←─→ AI 大脑（多个）
                              ↓
                          知识库（97 篇 / 8 学科）
                              ↓
                          数据库 + 缓存
```

**3 个亮点**：
1. **多 AI 协同**：8 个专职 Agent 分工（出题/追问/评分/报告）
2. **多模型路由**：主模型挂了自动切备用，用户无感知
3. **多学科覆盖**：计算机/经济/法学/哲学/英语 都能出题

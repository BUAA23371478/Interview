# 动态规划入门

## 核心思想

动态规划（DP）通过把问题分解为**重叠子问题**并记忆化结果，避免重复计算。
适用条件：
1. 最优子结构：原问题的最优解包含子问题的最优解
2. 重叠子问题：递归时会反复求解同一子问题

## 两种实现方式

### 自顶向下（记忆化递归）
```python
from functools import lru_cache
@lru_cache
def fib(n):
    if n < 2: return n
    return fib(n-1) + fib(n-2)
```

### 自底向上（递推）
```python
def fib(n):
    if n < 2: return n
    a, b = 0, 1
    for _ in range(n-1):
        a, b = b, a+b
    return b
```

## 经典模型

### 背包问题
- 0-1 背包：每件物品选或不选
  `dp[i][w] = max(dp[i-1][w], dp[i-1][w-wi] + vi)`
  空间优化到一维：内层倒序遍历 w
- 完全背包：每件物品无限选 → 内层正序
- 多重背包：每件物品最多 si 个 → 二进制拆分

### 最长公共子序列（LCS）
- 字符串问题经典 DP：`dp[i][j]` 表示 s1[:i] 和 s2[:j] 的 LCS 长度
- 转移：相等则 `+1`；否则取 max
- 输出 LCS 需要回溯

### 最长上升子序列（LIS）
- O(n²) DP：朴素
- O(n log n)：维护 tails 数组 + 二分

## 工程经验

- 状态定义决定一切：先把 dp 维度、含义写清楚再想转移
- 边界条件比转移更重要：dp[0][*]、dp[*][0] 必须初始化对
- 路径还原需要记录"从哪来"（如前驱指针）

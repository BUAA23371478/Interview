## 路由表

| 路径 | 页面 | 说明 |
|------|------|------|
| `/` | HomePage | 首页，两种模式入口 |
| `/practice` | PracticeSetup | 刷题主题输入 |
| `/practice/:sessionId` | PracticeSession | 刷题答题循环 |
| `/interview` | InterviewSetup | 面试设置（JD+简历+轮数） |
| `/interview/:sessionId` | InterviewSession | 面试一问一答 |
| `/interview/:sessionId/report` | InterviewReport | 复盘报告 |
| `/history` | HistoryOverview | 历史记录总览 |
| `/history/practice` | PracticeHistory | 刷题历史 + 统计 |
| `/history/practice/:sessionId` | PracticeSession | 复用刷题页查看历史详情 |
| `/history/interview` | InterviewHistory | 面试历史列表 |
| `/history/interview/:id` | InterviewDetail | 面试详情 + 报告 |

## 核心状态机

### 刷题模式
```
LOADING_QUESTION → ANSWERING → SUBMITTING → FEEDBACK_SHOWN
       ↑                                            │
       └────────── 点击"下一题" ←────────────────────┘
```

### 模拟面试
```
WAITING_QUESTION → RECEIVING_QUESTION → ANSWERING → SUBMITTING
                                                         │
                                              ┌─────────┼─────────┐
                                              │         │         │
                                          FOLLOW_UP  NEXT_ROUND  COMPLETED
                                              │         │         │
                                              └────┬────┘         ▼
                                                   │        生成复盘报告
                                                   │
                                              (循环回到 WAITING_QUESTION)
```

## 启动命令

```bash
# 进入前端目录
cd frontend

# 安装依赖（首次）
npm install

# 启动开发服务器（默认 http://localhost:5173）
npm run dev

# 生产构建（产物在 dist/）
npm run build

# 预览生产构建
npm run preview

# 类型检查
npx tsc -b
```

## 后端联调说明

开发环境下 Vite 自动将 `/api` 请求代理到 `http://localhost:8000`（后端 FastAPI 默认端口）。

启动后端后再启动前端即可联调：

```bash
# 终端 1：启动后端
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000

# 终端 2：启动前端
cd frontend
npm run dev
```
